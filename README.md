### 29.10.2026 — Юніт 3: система здоров'я

Що зроблено:
Додано поля `maxHealth`, `currentHealth`, функцію `ChangeHealth` з `Mathf.Clamp`. Налаштовано швидкість через інспектор (`speed`). Створено префаби аптечки супер-аптечки та зони шкоди, яка б'є робота поки він стоїть у ній. Реалізовано таймер невразливості.

Труднощі:
Робот «засинав» у зоні шкоди, через що вона переставала працювати. Проблему вирішено перемиканням Rigidbody 2D у режим `Never Sleep`.

Що зрозуміло:
Звичайний колайдер є твердою перешкодою, а тригер просто фіксує перетин межі й запускає код. Властивості (`get`) дозволяють іншим скриптам читати змінні.

Time Invincible:
Обрав `2.0f`. Це дає гравцеві 2 секунди, щоб вибігти з пастки, не втрачаючи все здоров'я за мить.
